## 🧑‍💻 About Me

Building performant web applications at the intersection of modern frontend architectures and scalable backend systems.

I specialize in architecting **React / Angular** frontends backed by **Node.js** and **PHP** services, with deep experience in **relational database** modeling, and **3D graphics optimization** using Three.js and Blender — turning heavy asset pipelines into fast, interactive web and AR experiences.
